# ITERA Bermatika

Pintu masuk bahan belajar matematika dari ITERA:
https://itera-bermatika.github.io/

## Bahan yang tersedia

- [Fondasi Matematika — bacaan prekalkulus interaktif](https://itera-bermatika.github.io/fondasi-matematika/)
- [Buku Prekalkulus — PDF draf pengembangan, Tri Utomo](https://itera-bermatika.github.io/prekalkulus-output/prekalkulus.pdf)
- [Buku Kalkulus — PDF](https://itera-bermatika.github.io/kalkulus-output/main.pdf)

Sumber bacaan interaktif dikelola terpisah di
[fondasi-matematika](https://github.com/itera-bermatika/fondasi-matematika).

## Mengubah landing page

Edit `index.html` untuk isi dan tautan, serta `style.css` untuk tampilan.
Jalankan `python -m http.server 8000` dan buka `http://localhost:8000` untuk
memeriksa hasil secara lokal. Publikasi GitHub Pages berasal dari cabang `main`
dan folder utama repositori. Tidak diperlukan proses build atau paket tambahan.
